## 2024-03-24 - [Vue IME Composition State Tracking]
**Learning:** When using custom bindings (`:value` and `@input`) instead of Vue's native `v-model` (which natively handles IME composition), state updates and component re-renders fire excessively during Japanese text composition. This is especially taxing when updates are routed through heavy state managers like Pinia.
**Action:** When working on input components in Vue that don't use `v-model` (for instance, because they need to dispatch specific Pinia actions), manually implement `isComposing` state tracking using `@compositionstart` and `@compositionend` to bypass state updates in `@input` handlers until the composition is complete.
